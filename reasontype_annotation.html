ReasonType step annotation

Human validation of the ReasonType taxonomy (TRACES paper)

What this is

This is a human-validation experiment for the ReasonType taxonomy used in the TRACES project. Each item is one reasoning step from a DeepSeek-14B trace on a MATH500 problem, previously labelled by GPT-4o-mini. Your task is to label the same steps blind (you won't see GPT-4o-mini's label) so we can measure:

  1. how consistent human annotators are with each other, and
  2. how well GPT-4o-mini's labels line up with human judgement.

You'll only be shown the problem and the single step to classify, which is the same information GPT-4o-mini had. Earlier steps in the trace are not available.

Accepted formats:
• CSV / TSV (e.g. a DataFrame exported with to_csv) with columns sample_id, step_id, step, category, and optionally problems (or problem). Extra columns such as level and an unnamed index column are ignored.
• JSON array of the same records (e.g. df.to_dict("records")), or JSON Lines.
• JSON object {"steps": [...], "problems": {...}, "full_trace": [...]}. Here problems is either {"0": "text", ...} keyed by sample_id or a list of {"sample_id":0,"problem":"..."}; full_trace has the same shape as steps but covers every step, and powers the "show previous steps" toggle.
The problem text can come from a separate problems block or from a problems/problem field on each step record.
